SQL analysis of a cirrhosis patient dataset using MySQL. It contains 20 queries that filter patients by clinical conditions (ascites, hepatomegaly, edema, spiders), calculate averages and extremes of lab values (bilirubin, cholesterol, albumin, platelets, prothrombin, triglycerides), compare groups by disease stage, sex, drug and survival status, and sort patients by age and follow-up days.

Skills shown: WHERE filtering, AND, LIKE, ORDER BY, aggregate functions (AVG, MIN, MAX, COUNT) and GROUP BY.

Files: the .sql file and the dataset CSV. Add the CSV to the repo and say where it came from.
